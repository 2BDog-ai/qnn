# 艺语音乐播放器 - 构建说明

## 🎵 关于证书验证问题的解决方案

由于应用未经过 Apple 官方签名认证，在某些 macOS 版本（特别是较新版本）上可能会遇到"应用已损坏"的提示。

## 🔧 解决方案

我们提供了多种自动化解决方案：

### 1. 安装助手（推荐）
- **文件**: `install-helper.sh` 
- **用途**: 用户友好的图形化安装助手
- **使用**: 在 DMG 中显示为 `🔧 安装助手.command`
- **功能**: 自动执行 `xattr -cr` 命令清除隔离属性

### 2. 智能启动器
- **文件**: `app-launcher.sh`
- **用途**: 启动时自动检测并修复证书问题
- **使用**: 在 DMG 中显示为 `🚀 启动应用.command`
- **功能**: 静默处理兼容性问题并启动应用

### 3. DMG 构建器
- **文件**: `build-dmg.sh`
- **用途**: 创建包含所有助手工具的完整安装包
- **功能**: 自动打包应用、助手和说明文档

## 📦 构建流程

1. **构建应用**:
   ```bash
   npm run build:mac
   ```

2. **创建 DMG**:
   ```bash
   cd build
   ./build-dmg.sh
   ```

3. **分发给用户**:
   - 用户下载并打开 DMG
   - 拖拽应用到 Applications
   - 双击"安装助手"优化兼容性
   - 正常使用应用

## 🛠️ 技术原理

### 问题根源
macOS 的 Gatekeeper 会为从网络下载的应用添加 `com.apple.quarantine` 扩展属性，阻止应用运行。

### 解决方法
使用 `xattr -cr` 命令清除所有扩展属性：
```bash
xattr -cr /Applications/艺语音乐播放器.app
```

### 自动化实现
- **安装助手**: 用户友好的交互式脚本
- **启动器**: 后台静默处理，对用户透明
- **DMG 集成**: 将解决方案打包在安装包中

## 📋 用户体验流程

1. **下载**: 用户下载 DMG 文件
2. **安装**: 拖拽应用到 Applications
3. **优化**: 双击安装助手（一次性操作）
4. **使用**: 正常启动和使用应用

## 🔒 安全说明

- 清除扩展属性是标准的 macOS 操作
- 不会修改应用本身的代码
- 不会影响系统安全性
- 等同于用户手动执行终端命令

## 📝 文件说明

| 文件 | 用途 | 显示名称 |
|------|------|----------|
| `install-helper.sh` | 交互式安装助手 | 🔧 安装助手.command |
| `app-launcher.sh` | 智能启动器 | 🚀 启动应用.command |
| `build-dmg.sh` | DMG 构建脚本 | - |
| `安装说明.txt` | 用户说明文档 | 📖 安装说明.txt |

这套解决方案让用户无需手动输入终端命令，通过简单的双击操作就能解决证书验证问题。
