# DMG 安装包说明

## 安装步骤

1. **拖拽安装**: 将"艺语音乐播放器"拖拽到右侧的"Applications"文件夹
2. **运行安装助手**: 双击"艺语音乐播放器安装助手"来优化系统兼容性
3. **启动应用**: 现在您可以从启动台或应用程序文件夹启动艺语音乐播放器了

## 关于安装助手

"艺语音乐播放器安装助手"会自动处理 macOS 的安全限制，确保应用能够正常运行。这个步骤是可选的，但强烈建议执行以获得最佳体验。

如果您遇到"应用已损坏"的提示，请运行安装助手或在终端中执行：
```bash
sudo xattr -cr /Applications/艺语音乐播放器.app
```

## 系统要求

- macOS 10.15 或更高版本
- 管理员权限（用于安装助手）

## 常见问题

**Q: 为什么需要运行安装助手？**
A: macOS 的安全机制（Gatekeeper）会阻止未签名的应用运行。安装助手会移除这些限制。

**Q: 安装助手是否安全？**
A: 是的，安装助手只是执行 `xattr -cr` 命令来移除隔离属性，不会修改系统或应用文件。

**Q: 可以跳过安装助手吗？**
A: 可以，但如果应用无法启动，您需要手动在终端执行清理命令。
